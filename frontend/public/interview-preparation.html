60-second project introduction

“I built Quiz Master for students in classes 6–12 who want practice questions based on their NCERT textbooks. A Python ingestion pipeline extracts chapter and topic content from the PDFs and stores embeddings in Chroma. The React app lets a student choose a class, subject, scope, difficulty and question types. The FastAPI backend first reuses unseen questions from PostgreSQL, generates any shortfall from textbook chunks using an LLM, then grades the attempt and updates the student's progress.”
